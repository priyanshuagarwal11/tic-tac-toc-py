❌⭕ Tic Tac Toe Game in Python

A console-based Tic Tac Toe game built using pure Python.
This project is beginner-friendly and focuses on game logic, loops, and condition handling.

2 Player mode

Turn-based gameplay

Win detection (row, column, diagonal)

Draw detection

Simple & clean console interface

🛠 Tech Stack

Python 3

No external libraries required
