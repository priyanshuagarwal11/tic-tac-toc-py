❌⭕ Tic Tac Toe Game in Python

A console-based Tic Tac Toe game built using pure Python.
This project is beginner-friendly and focuses on game logic, loops, and condition handling.

🎮 Game Features

2 Player mode

Turn-based gameplay

Win detection (row, column, diagonal)

Draw detection

Simple & clean console interface

🛠 Tech Stack

Python 3

No external libraries required
📁 Project Structure
tic-tac-toe/
│
├── tic_tac_toe.py
└── README.md

▶ How to Run the Game

Make sure Python is installed

Open terminal in project folder

Run the command:

python tic_tac_toe.py
🎯 How to Play

Positions are numbered as:

1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9


Player X starts first

Enter position number (1–9)

First to match 3 symbols wins
